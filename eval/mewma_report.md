# 다변량 이상 탐지 (MEWMA) 비교

`cd qms-app && ./gradlew mewmaEval` 로 다시 만들 수 있습니다.

- 데이터: 탐지 평가(E2)·EWMA 비교와 같은 시뮬레이터 seed 5개. 운영 SpcEngine 이 걸러 낸 깨끗한 값을 `MewmaMonitor` 에 넣음
- MEWMA: 기준 100 shot 으로 센서 7개 평균·공분산, z_t = λ(x_t−μ) + (1−λ)z_{t−1}, T² = zᵀΣ_z⁻¹z > h 면 경보, 설비별 100 shot 반복 억제
- h: 센서 7개 χ² 의 상위 0.1%(24.3)·0.01%(29.9)·0.001%(35.3)
- 채점: E2 와 같은 50 shot 창 혼동행렬·고장별 탐지 지연. seed 평균 ± 표본 표준편차

## 읽는 법

- MEWMA 는 센서 사이의 정상 관계(공분산)에서 벗어난 작은 변화를 누적해서 봅니다. 서서히 진행되는 고장의 지연이 줄어드는지가 핵심입니다.
- 센서별 EWMA(eval/ewma_report.md)는 센서 7개를 따로 봐서 오경보가 많았습니다. MEWMA 는 통계량이 하나라 같은 오경보 수준에서 더 민감할 수 있습니다.
- 불량률(P 관리도)은 보지 않으므로 단독보다는 '지금 규칙 + MEWMA' 행으로 판단합니다. 경보가 늘면 LLM 비용·검토 부담도 늘어납니다.
