# SOP-INJ-001 사출 성형기 일상 점검
문서번호: SOP-INJ-001 · 개정 2 · 가상 문서(포트폴리오 시연용, 실제 회사 문서 아님)
관련 센서: moldTemp, barrelTemp, injectionPressure, holdingPressure, cushion, cycleTime, motorCurrent
관련 원인 코드: (공통)

## 1. 적용 범위
사출 성형기(IMM) 전 설비. 작업 시작 전, 금형 교체 후, 4시간 이상 정지 뒤 재가동할 때 실시한다.

## 2. 작업 시작 전 점검
1. 실린더 온도(barrelTemp)가 설정값 ±5℃ 안에 들어온 뒤 30분 이상 유지되었는지 확인한다.
2. 금형 온도(moldTemp)가 설정값 ±3℃ 안인지 확인하고, 냉각수 유량계가 정상 범위(8~12 L/min)인지 본다.
3. 호퍼 원료 잔량과 건조기 표시(이슬점 −40℃ 이하)를 확인한다.
4. 초품 3개를 검사해 외관(미성형·버·은줄)과 핵심 치수를 기록한다.

## 3. 운전 중 확인
- 쿠션량(cushion)이 설정값 ±0.5 mm 안에서 안정적인지 확인한다. 계속 줄거나 흔들리면 SOP-INJ-012 를 따른다.
- 사이클 타임(cycleTime)이 기준보다 5% 이상 길어지면 금형 냉각 계통(SOP-INJ-011)을 먼저 본다.
- 경보가 나면 설비를 바로 멈추지 말고 품질 담당자에게 알린 뒤, 해당 SOP 의 판단 절차를 따른다.

## 4. 기록
점검표(양식 F-INJ-001)에 시각, 설비, 확인 값, 이상 유무를 남긴다. 이상이 있으면 정비 요청서를 발행한다.
