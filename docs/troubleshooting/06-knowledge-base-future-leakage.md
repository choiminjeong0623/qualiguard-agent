# 06. 승인한 AI 초안이 지식저장소로 돌아오며 생긴 세 번째 미래 정보 누수

- 발견일: 2026-11-15 (F-10 지식저장소 반영 구현 중, 설계 점검)
- 영향: 그대로 두었다면 재생 평가와 재분석에서 같은 고장의 "정답 보고서"를 미리 보고 판단 → 평가가 다시 유리해짐
- 상태: **해결** (유사 사례 검색에 분석 기준 시점 `@AsOf` 적용)
- 관련: [ADR-008 결정 6](../decisions/ADR-008-agent-design.md), [ADR-007 결정 4](../decisions/ADR-007-sqlserver-qms-schema.md), [장애 분석 04](04-agent-evaluation-leakage.md)

장애 분석 04에서 "미래 정보는 여러 경로로 새어 들어온다"고 적었습니다. 이 문서는 **새 기능을 넣으면서 세 번째 경로가 생긴 것**을 구현 단계에서 찾아 막은 기록입니다.

---

## 1. 무엇이 바뀌었나

F-10(승인된 부적합을 다음 분석의 유사 사례로 재사용)을 넣으면서 흐름이 하나로 이어졌습니다.

```
경보 → 에이전트 초안(AI-2026-xxxx) → 품질 담당자 승인 → 지식저장소(유사 사례 검색 대상) → 다음 분석
```

운영에서는 바라던 동작입니다. 사람이 확정한 사례가 쌓일수록 다음 판단의 근거가 늘어납니다.

## 2. 문제: 지난 경보를 다시 분석할 때

검증 중 히터 열화 초안 AI-2026-0035를 승인했습니다. 이후 같은 히터 열화 구간을 재생 평가로 다시 돌리면:

| 조회 | 결과 |
|---|---|
| 기준 시점 없이 유사 사례 검색 | **AI-2026-0035가 나옴** (그 고장 자체의 확정 보고서) |
| 검색 기준 = 히터 첫 경보 시각 | 나오지 않음 |

shot 325의 경보를 분석하는 시점에는 아직 존재하지 않았던 보고서입니다. 데이터(`@AsOf`)와 경보(시간 순 재생)를 막았어도, **지식저장소 경로로 같은 고장의 정답이 들어오는** 셈입니다.

| 누수 경로 | 발견 | 조치 |
|---|---|---|
| 1. 미래 공정 데이터 | 에이전트 구현 중 | 도구 조회에 `@AsOf` ([ADR-007](../decisions/ADR-007-sqlserver-qms-schema.md)) |
| 2. 미래 경보 (사건 묶기) | 반복 평가 | 시간 순 재생 평가 ([04](04-agent-evaluation-leakage.md)) |
| 3. **나중에 승인된 사례** | **F-10 구현 중 (이번)** | 유사 사례 검색에도 `@AsOf` |

## 3. 조치

| 조치 | 파일 |
|---|---|
| `usp_FindSimilarNcr`에 `@AsOf` 추가: 그 시점까지 승인된 사례만 검색. 결과에 원인 코드·출처(사람 작성/AI 승인) 추가 | `infra/mssql/init/04_procedures.sql` |
| 에이전트 도구가 분석 기준 시점을 검색에도 넘김 (모델이 바꿀 수 없게 도구 인자로 노출하지 않음) | `agent/QualityTools.java` |
| 과거 사례 숨김 실험을 고정 4건 대신 **원인 코드 기준**으로 숨김 (AI 승인 사례도 함께 숨기기 위해) | `scripts/evaluate_agent.py` |
| 테스트: 기준 시점 전달 확인 | `QualityToolsAsOfTest` |

검증: 재생 분석 1회에서 검색에 기준 시점이 넘어갔고, 참고 사례는 NCR-2025-0012(사람이 작성한 과거 사례)만 나왔습니다.

## 4. 재발 방지

- 에이전트가 읽는 **모든 조회 경로**에 "분석 시점에 존재했는가"를 묻습니다. 새 데이터 출처를 도구에 연결할 때 체크 항목으로 둡니다.
- 숨김 실험은 고정 번호가 아니라 **조건(원인 코드)**으로 숨겨, 새로 쌓인 사례도 빠짐없이 가립니다.

## 5. 배운 점

- **기능을 더하면 누수 경로도 새로 생긴다.** 학습 루프(승인 → 재사용)는 운영에서는 장점이지만, 평가에서는 정답이 문제지로 되돌아오는 길이 됩니다.
- **원칙 하나로 막는다.** 경로마다 다른 땜질 대신 "그 시점에 알 수 있던 것만 쓴다"를 데이터·경보·지식저장소에 똑같이 적용했습니다.
