# ADR-015. MQTT 장비 인증과 토픽별 접근 권한 (사용자명 = 설비 ID)

- 상태: 채택 (2026-11-15)
- 관련 요구사항: [N-07, N-08](../03-future-local-llm-and-device-security.md)
- 참고: ADR-014 번호는 당시 브랜치에만 있던 유사 사례 의미 검색이 쓰고 있어 건너뛰었습니다(2026-11-21 main 머지).

## 배경
센서 데이터 시스템의 입구는 사람이 아니라 설비입니다. 지금까지 Mosquitto 는 `allow_anonymous true` 라서, 같은 네트워크에 있는 누구나
`factory/LINE1/IMM-01/telemetry` 에 가짜 값을 보내 경보와 AI 초안을 만들 수 있었습니다. 반대로 아무나 모든 설비 데이터를 구독할 수도 있었습니다.

## 결정
1. **계정 없는 접속은 거부**한다 (`allow_anonymous false`, 비밀번호 파일).
2. **장비마다 계정을 하나씩** 두고, **사용자명 = 설비 ID** 로 정한다. 시뮬레이터도 설비마다 따로 접속한다.
3. **토픽 권한(ACL)** 은 두 줄로 끝낸다.
   - 장비: `pattern write factory/+/%u/telemetry` → 자기 설비 토픽에 쓰기만. 다른 설비 토픽 발행·구독은 거부.
   - 브리지(`qg-bridge`): `topic read factory/+/+/telemetry` → 모든 설비 데이터를 읽기만.
4. **비밀번호는 `.env` 에만** 둔다. `scripts/mqtt_users.sh` 가 비어 있는 비밀번호를 무작위로 만들어 `.env` 에 넣고, 해시만 담긴
   `infra/mosquitto/passwd` 를 만든다. 계정 파일도 커밋하지 않는다.
5. 거부 사례를 **시험 스크립트**(`scripts/test_mqtt_acl.sh`)로 남긴다.

| 선택지 | 판단 |
|---|---|
| 인증 없음 (기존) | 가짜 데이터 주입·도청을 막을 수 없음 |
| 장비 공용 계정 하나 | 계정이 하나 새면 모든 설비를 흉내 낼 수 있고, ACL 로 설비별 제한을 못 함 |
| **장비별 계정 + `%u` 패턴 ACL** | 설비가 늘어도 ACL 은 그대로, 계정만 추가. 한 설비 계정이 새도 그 설비 토픽만 영향 |
| 장비별 인증서(mTLS) | 가장 강하지만 인증서 발급·갱신 체계가 필요 → 다음 단계(N-09) |
| OAuth2/JWT | 사람 로그인용. 설비는 브라우저도 사람도 없어 맞지 않음 |

## 결과 (시험)
`./scripts/test_mqtt_acl.sh` 6항목 모두 통과 (로컬 Mosquitto 2.0.18):

| 시험 | 결과 |
|---|---|
| 계정 없는 접속 | 거부 (Not authorized) |
| 틀린 비밀번호 | 거부 |
| IMM-01 계정 → `factory/LINE1/IMM-01/telemetry` 발행 | 브리지 계정이 받음 |
| IMM-01 계정 → `factory/LINE1/IMM-02/telemetry` 발행 | 전달되지 않음 |
| 브리지 계정 발행 | 전달되지 않음 (읽기만) |
| IMM-01 계정 구독 | 아무것도 받지 못함 |

같은 스크립트를 인증 없는 브로커에 돌리면 5항목이 실패해, 시험이 실제로 차이를 잡는 것도 확인했습니다.
브리지(Paho)는 계정이 맞으면 접속·구독 후 메시지를 받고, 틀리거나 없으면 `Not authorized (135)` 로그를 남기고 5초마다 다시 접속을 시도합니다.

## 한계와 다음 단계
- Mosquitto 는 ACL 로 막힌 발행을 접속을 끊지 않고 **조용히 버립니다**(QoS 1 이어도 발행자는 성공으로 봄). 그래서 잘못 설정된 장비는
  브로커 로그가 아니면 알아채기 어렵습니다 → 브리지 쪽에서 설비별 수신이 끊긴 것을 감시하는 지표가 필요합니다.
- 구독도 마찬가지로 SUBACK 은 성공으로 오고, 전달 단계에서 거릅니다.
- 평문(1883)입니다. 비밀번호가 네트워크에 그대로 지나가므로 운영에서는 TLS(8883, N-09)가 필요합니다.
- 계정 파일을 바꾸면 브로커를 다시 띄워야 합니다(`docker compose restart mosquitto`).
