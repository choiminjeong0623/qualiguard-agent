# ADR-005. 탐지는 SPC, 판단은 LLM이 맡는다

- 상태: 채택
- 날짜: 2026-11-14

## 배경
센서 데이터에서 이상을 찾고 원인을 추정하는 일에 AI를 어디까지 쓸지 정해야 했습니다.

## 고려한 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 모든 shot 데이터를 LLM에 넣어 이상 판단 | 구현이 단순해 보임 | shot마다 호출 → **비용·지연이 큼**. 같은 데이터에도 판단이 흔들릴 수 있고, 왜 이상인지 **설명·재현이 어려움** |
| B. 머신러닝 이상 탐지 모델만 사용 | 자동으로 패턴 학습 | 결과를 현장에 설명하기 어렵고, 원인 추정·보고서 작성은 여전히 사람 몫 |
| **C. 탐지는 SPC 관리도(규칙), 원인 추정과 보고서는 LLM** | 탐지는 빠르고 결과가 늘 같으며 현장 품질팀이 이미 아는 방식. LLM은 사람의 경험이 필요한 일에만 사용 | 규칙의 기준값을 잘 정해야 함 |

## 결정
**C**를 택했습니다.

| 역할 | 담당 | 이유 |
|---|---|---|
| 이상 탐지 | SPC 관리도 4종 (개별값, X̄, S, p) | 품질 현장의 표준 기법이라 결과를 현장에서 그대로 이해·신뢰할 수 있음 |
| 원인 추정, 보고서 초안 | LLM 에이전트 | 여러 근거를 종합해 문장으로 설명하는 일은 LLM이 잘함 |
| 최종 판단 | 품질 담당자 | 책임 소재가 분명해야 함 |

## 근거
- **비용**: 시뮬레이션 4,000 shot에서 경보는 97건. LLM 호출 대상이 전체의 **2.4%**로 줄어듭니다. 같은 규칙·센서 경보를 100 shot 동안 다시 내지 않는 반복 억제도 같은 목적입니다.
- **설명 가능성**: "5 shot 평균이 관리 하한을 연속 2회 벗어남"처럼 탐지 이유가 분명합니다.
- **역할에 맞는 도구**: 규칙은 "언제 이상한가"를, LLM은 "왜 이상한가"를 답합니다.
- **AI가 틀릴 때의 안전장치**: 규칙이 오경보를 내더라도 LLM이 근거를 보고 "단발성 변동, 관찰"로 판단할 수 있고, 최종 확정은 사람이 합니다.

## 결과
- 경보에 에이전트용 근거(최근 값 30개, **모든 센서의 z 점수**, 최근 불량 유형)를 함께 담습니다. z 점수를 보면 "온도 −5.1σ, 압력 +1.9σ, 전류 +1.9σ"처럼 여러 센서의 움직임을 한눈에 비교할 수 있습니다.
- 오경보를 줄이기 위해 X̄·S 관리도는 "연속 2회 이탈"로 확인합니다.
- 다음 단계에서 같은 설비·같은 시간대의 경보를 하나의 사건으로 묶으면 LLM 호출을 더 줄일 수 있습니다.
