# ADR-011. QMS 로그인: DB 사용자 + BCrypt, 역할 두 가지, 에이전트 API 는 로컬 도구용으로 열어 둠

- 상태: 채택
- 날짜: 2026-11-15
- 관련: F-08(담당자 검토·승인), N-05(AI 판단을 사람이 검증), [ADR-009](ADR-009-qms-review-screen.md) 한계 "로그인 없음"을 해소

## 배경
검토 화면([ADR-009](ADR-009-qms-review-screen.md))은 검토자 이름을 입력받아 이력에 남겼습니다. 누구나 아무 이름으로 승인할 수 있어, **"누가 승인했는가"라는 이력의 의미가 약했습니다.** 승인 결과는 지식저장소(F-10)와 MES/ERP(F-09)로 이어지므로 승인자를 확실히 해야 합니다.

## 결정 1. Spring Security 폼 로그인, 사용자는 DB(`app_user`), 비밀번호는 BCrypt
| 선택지 | 장단점 |
|---|---|
| 설정 파일에 사용자 고정 | 간단하지만 비밀번호가 저장소나 설정에 남기 쉬움 |
| 사내 SSO(OIDC) | 운영에 맞지만 로컬 시연에 인증 서버가 필요 |
| **DB 테이블 + BCrypt** | QMS 데이터와 같은 SQL Server 에 둠. 나중에 SSO 로 바꿔도 역할·이력 구조는 그대로 |

- 비밀번호는 `{bcrypt}` 해시로만 저장합니다 (`DelegatingPasswordEncoder`, 나중에 알고리즘을 바꿔도 기존 해시가 동작).
- **기본 계정 비밀번호를 저장소에 두지 않습니다.** `09_users.sql`은 표만 만들고, 앱이 시작할 때 `.env`의 `QG_REVIEWER_*`·`QG_VIEWER_*` 값으로 **없는 계정만** 만듭니다. 이미 있는 계정의 비밀번호는 바꾸지 않습니다. 계정이 하나도 없으면 로그에 방법을 안내합니다.

## 결정 2. 역할은 두 가지
| 역할 | 할 수 있는 일 |
|---|---|
| `REVIEWER` (품질 담당자) | 목록·상세 조회, 초안 수정, 승인·반려, 조치 완료 |
| `VIEWER` (조회 전용) | 목록·상세 조회 |

- 검토 이력의 검토자는 **로그인한 사용자의 표시 이름**입니다. 요청 본문에 다른 이름을 보내도 쓰지 않습니다.
- **작성·승인 분리(초안을 고친 사람은 승인 못 함)는 넣지 않았습니다.** 승인에는 확정 원인 입력이 필요해(ADR-009) 검토자가 직접 고친 뒤 승인하는 것이 기본 흐름이고, 시연 환경에는 검토자가 한 명뿐이라 막히기 때문입니다. 운영에서 필요하면 `usp_ReviewNcr`에서 마지막 수정자와 승인자를 비교해 막을 수 있습니다.

## 결정 3. 에이전트 API·actuator 는 열어 둔다 (로컬 도구용)
| 경로 | 인증 | 이유 |
|---|---|---|
| `/qms/**` (화면) | 로그인 필요, 안 했으면 로그인 화면으로 | 사람이 쓰는 화면 |
| `GET /api/qms/**` | REVIEWER·VIEWER | |
| 쓰기 `/api/qms/**` | REVIEWER + CSRF 토큰 | 승인·반려는 지식저장소·MES/ERP 로 이어짐 |
| `/api/agent/**`, `/actuator/**` | **없음** | 평가 스크립트(`evaluate_agent.py`)와 모니터링이 그대로 동작해야 함 |

- 에이전트 API 는 사람이 아닌 로컬 스크립트가 부르므로 CSRF 검사에서 뺐습니다.
- **운영에서는 이 경로를 내부망으로 제한하거나 별도 인증(서비스 토큰 등)을 붙여야 합니다.** 시연용 결정임을 여기에 남깁니다.

## 결정 4. CSRF 는 쿠키 → 헤더
화면 JS 가 `XSRF-TOKEN` 쿠키 값을 `X-XSRF-TOKEN` 헤더로 보냅니다. 쿠키가 첫 요청부터 내려가도록 요청마다 토큰을 읽는 필터를 두었습니다. 로그인 폼도 같은 값을 `_csrf`로 보냅니다. 로그인하지 않은 API 요청은 로그인 화면으로 보내지 않고 401 을 돌려줍니다 (화면 JS 가 받아서 로그인 화면으로 이동).

## 결과
- 화면 머리글에 로그인 사용자와 역할, 로그아웃. 조회 전용 계정은 수정·승인 단추가 잠기고 안내가 나옴
- `GET /api/qms/me` (이름·역할)

## 한계
- 비밀번호 변경·잠금(로그인 실패 횟수)·감사 로그(로그인 기록) 화면은 없습니다.
- 세션은 앱 메모리에 있어 앱을 다시 시작하면 다시 로그인해야 합니다.
